Mailbox Lead Generation

Turn incoming email into clean CRM leads

Mailbox Lead Generation adds an intermediate inbox for incoming email. Every message fetched from your mail server becomes a record that is classified by destination address, optionally triaged by AI, matched against your product catalog, and then converted into a clean crm.lead.

Features

What it does

Triage inbox

Emails land as Mailbox records first, so nothing reaches the sales pipeline unreviewed.

Classification by address

Inquiry addresses (buyers) and acquisition addresses (suppliers) each follow their own flow.

Optional AI triage

Any OpenAI-compatible endpoint summarizes, categorizes and extracts contact data.

Catalog matching

Keywords from the email are matched against your products (any type) and offered as suggestions.

Spam rejection

Reject an email in one click before it ever touches the pipeline.

Full traceability

The original message, classification, AI output and suggestions stay on the record.

Getting started

How it works

1
Install
Requires crm. The Python requests library is used for AI triage.
2
Set the addresses
Settings → Mailbox Lead Generation: list your inquiry and acquisition addresses.
3
Connect your mailbox
Create an Incoming Mail Server that creates mailbox.lead.generation records.
4
Optional: connect AI
Base URL, API key, model, temperature and retries. Leave the key empty to disable AI. A cron processes the queue every 5 minutes.
5
Review and convert
Read the email, its classification and suggestions, then Convert to Lead or reject it.

Details

Feature Detail
AI providers OpenAI, Azure OpenAI, local vLLM or Ollama — any OpenAI-compatible endpoint
Works without AI Every feature except triage works with no API key
Queue processing Scheduled action every 5 minutes
Languages English and Spanish (es, es_CL)

Requirements

Item Value
Odoo 16.0 — Community or Enterprise
